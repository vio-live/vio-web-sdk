Vio Web SDK — QA local

Cómo usar esta página
  • npm run dev y abre http://127.0.0.1:5173/?env=testing&campaignId=18
  • El código de descuento es el de la campaña: se pone en el dashboard (QA), en la campaña, por sponsor. El SDK lo pone solo en el carrito de esa marca; la barra de arriba dice cuál. Cambiarlo o quitarlo en el dashboard y volver a la pestaña tras más de 5 min (o recargar): el carrito lo cambia o lo quita, con su regalo.
  • apiKey (si no, VITE_VIO_API_KEY en .env.local) · env = testing | production · campaignId · discountCode (un código de la página, que pisa el de la campaña) · discountField = true | false · productIds = 1,2,3 · vio_discount funciona como en cualquier página.
  • 1) Ficha con carrito vacío: «Tøm handlekurven», abre un producto, «Kjøp nå med Vipps». · 2) Carrito: añade, «Handlekurv», Vipps (Express). · 3) Checkout: en el carrito «Til kassen», Vipps, el formulario, «Betal … med Vipps».
  • Vuelta de Vipps: llega a https://127.0.0.1:5173/…, que no se sirve — cambia https por http en la barra para ver el recibo.
